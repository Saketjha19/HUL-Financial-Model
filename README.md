# HUL Financial Model

A financial valuation model for **Hindustan Unilever Limited (HUL)**, built in Excel.

## Contents

The workbook (`HUL_Financial_Model.xlsx`) includes the following sheets:

- **Financial_statement** – Core financial statements
- **Data Sheet** – Underlying input data
- **WACC** – Weighted Average Cost of Capital calculation
- **BETA** – Beta calculation
- **data for growth** – Growth rate inputs/assumptions
- **Intrinsic Growth** – Intrinsic growth rate analysis
- **Market Returns** – Market return calculations
- **DCF** – Discounted Cash Flow valuation
- **Comparable comps** – Comparable companies analysis
- **Precedent Transaction Analysis** – Precedent M&A transaction analysis

## Usage

Open `HUL_Financial_Model.xlsx` in Excel (or a compatible spreadsheet application) to explore the model, review assumptions, and adjust inputs as needed.
